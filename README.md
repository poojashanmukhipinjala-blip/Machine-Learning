# Machine-Learning
## 📖 About This Project

This repository documents my **data science learning journey**, one topic at a time.
Each topic is explained with a hands-on example on the classic **Titanic dataset**,
so you can read the concept, see the charts, and run the code yourself.

### What you'll find here
- 📊 **Exploratory Data Analysis (EDA):** data inspection, cleaning, univariate,
  bivariate and multivariate analysis, plus statistical tests
- 🔧 **Feature Engineering:** transformation, construction, selection and extraction,
  with definitions, types and examples
- 📓 **Colab-ready notebooks:** open them in one click, no setup needed
- 🎨 **Visual carousels:** PDF and video versions I share on LinkedIn
- 🐍 **Reusable Python scripts** for generating the charts and carousels

### Who is this for?
Beginners learning data science, students preparing for data analyst roles,
and anyone who wants a clear, practical reference for EDA and feature engineering.

### Tech stack
Python • Pandas • NumPy • Matplotlib • Seaborn • SciPy • Scikit-learn • Jupyter / Google Colab

### Key findings from the Titanic analysis
- Only **38.4%** of passengers survived
- **Women 74%** survived vs **men 19%**
- Survival by class: **63%** (1st), **47%** (2nd), **24%** (3rd)
- Log-transforming `fare` reduced its skewness from **4.79 to 0.39**
